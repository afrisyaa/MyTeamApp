## Features

- **Home**: welcome page and features page, with swipeable pages on a gradient background
- **Team**: an "About My Team" page with a profile for each member (photo, bio and details)
- **Team info**: an overview of the team
- A tab bar for moving between pages

## Requirements

- macOS with Xcode
- iOS 26.5 or later (simulator or device)

## How to run

1. Clone the repo:
   ```bash
   git clone https://github.com/afrisyaa/MyTeamApp.git
   ```
2. Open `MyTeamApp.xcodeproj` in Xcode.
3. Choose an iPhone simulator and press **Run** (⌘R).
